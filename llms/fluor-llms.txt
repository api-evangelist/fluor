# Fluor Corporation

> Fluor Corporation (NYSE: FLR) is a Fortune 500 engineering, procurement, construction and
> maintenance (EPCM) company headquartered in Irving, Texas, delivering capital projects and
> project-management services for energy, chemicals, life sciences, mining, metals, advanced
> technology, infrastructure and government clients worldwide. Fluor sells engineering and
> construction services, not software: as of 2026-09-10 it operates no developer program,
> publishes no API reference, and serves no machine-readable API contract of any kind. This
> file is generated by API Evangelist from the public Fluor web estate so an agent asking
> "where is Fluor's API?" gets a correct answer instead of a guess.

## API surface

- **No public API.** Fluor publishes no OpenAPI, AsyncAPI, GraphQL SDL, Protobuf, WSDL,
  Postman collection or JSON Schema. There is no `api.fluor.com`, `developer.fluor.com`,
  `developers.fluor.com`, `docs.fluor.com` or `apis.fluor.com` — all resolve NXDOMAIN.
- **No MCP server, no A2A agent card, no `llms.txt` of Fluor's own.**
  `https://www.fluor.com/llms.txt` returns 404.
- **Business-to-business integration runs on third-party platforms.** Fluor's supply-chain
  collaboration is conducted through SAP Ariba and Workday, whose contracts belong to those
  vendors, not to Fluor.
